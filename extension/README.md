# Resumme Builder - Chrome Extension (Manifest V3)

A lightweight, zero-telemetry Chrome extension built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**. It connects directly to the Resumme Builder Multi-Agent backend to extract job descriptions from 21+ job portals and download ATS-proof, single-column tailored resumes with a single click.

---

## Features

- **Strict Manifest V3 Compliance:** Complies with `.agent/rules/portal-ext-rule.md`.
- **Minimal Permissions Principle:** Only requests `activeTab`, `scripting`, and `storage`. Zero broad host permissions (`<all_urls>` is forbidden).
- **Multi-Layer Robust Extraction:**
  1. **Layer 4 Priority:** User text selection / cursor highlight fallback.
  2. **Layer 1:** JSON-LD structured data (`@type: "JobPosting"`).
  3. **Layer 2:** Semantic & portal-specific containers (Workday, Indeed, LinkedIn, Naukri, Foundit, Lever, Greenhouse, Ashby, etc.).
  4. **Layer 3:** Clean visible DOM extraction stripped of navbars, footers, scripts, and cookie banners.
- **Dynamic Content Resilience (WC-4):** Automatic 1.2s retry loop for client-rendered Single-Page Applications (SPAs).
- **Direct Agentic Pipeline Integration:** Calls FastAPI backend (`POST /api/v1/pipeline/run` and `POST /api/v1/pdf/generate`).
- **1-Click Verified PDF Download:** Downloads candidate-customized, ATS-parseable single-column PDF resume generated by ReportLab.

## Development & Build Setup

### 1. Install Dependencies
```bash
cd extension
npm install
```

### 2. Build Unpacked Extension
```bash
npm run build
```
This runs TypeScript checking and Vite compilation, outputting the unpacked extension directly into `extension/dist/`.

---

## Loading into Google Chrome

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked** in the top-left toolbar.
4. Select the `extension/dist/` folder from this repository.
5. The **Resumme Builder - ATS Resume Tailor** icon will appear in your Chrome toolbar.

---

## Using the Extension

1. Ensure the FastAPI backend is running locally:
   ```bash
   cd backend
   uvicorn app.main:app --reload --port 8000
   ```
2. Navigate to any job posting on LinkedIn, Naukri, Indeed, Workday, etc.
3. Click the **Resumme Builder** extension icon.
4. The extension automatically detects the portal and extracts the job description.
5. Click **Tailor ATS Resume (3-Agent Core)**.
6. Review the ATS match score (>=85%) and matched keywords, then click **Download ATS Resume (PDF)**.
